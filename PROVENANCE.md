# Source and attribution

TVLevels contains a native Swift/AppKit panel and Python chart-level detection
and inspection tools. It is distributed under the [MIT License](LICENSE).

The app was developed alongside TradingView MCP and extracted into a separate
application. Original copyright and license notices are retained, including the
notice for [tradesdontlie](https://github.com/tradesdontlie), creator of the
original [TradingView MCP](https://github.com/tradesdontlie/tradingview-mcp).
TVLevels contributors' additions use the same license.

The separate runtime dependency is
[madiver/TradingView-MCP](https://github.com/madiver/TradingView-MCP), pinned by
full commit SHA in [dependencies.lock.json](dependencies.lock.json). Its source,
license, provenance, and npm dependency notices remain in the downloaded checkout.
See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The app icon was generated for TVLevels using an image-generation tool. Its
creation prompt is retained in [panel/assets/PROMPT.md](panel/assets/PROMPT.md).
It does not use a TradingView logo.

This publication checkout starts with fresh Git history. Local configuration,
runtime state, chart snapshots, generated applications, and earlier private Git
objects are not part of the source distribution. A new history does not change
the original authorship or license obligations.
