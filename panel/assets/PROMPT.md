# Daily Levels app icon

Created with the built-in imagegen tool. `DailyLevels.png` is the original
transparent source. The panel build uses macOS sips and iconutil to package all
standard icon resolutions into the app bundle's `DailyLevels.icns`.

Prompt:

> Use case: logo-brand. Asset type: a single macOS application icon for a small utility called Daily Levels, which draws daily support, resistance, gap, window and premarket lines on stock charts. Create a polished square app icon: deep navy rounded-square tile with a subtle beveled edge, a compact bold white and pale teal candlestick chart in the center, crossed by three clean horizontal price-level lines in cyan, orange and fuchsia. Strong, simple silhouette that remains recognizable at 32 pixels. Modern professional macOS utility aesthetic, crisp geometric forms, restrained depth. The tile should fill about 86% of the square canvas, with a genuinely transparent outer margin. Front-on centered view. No text, numbers, axes labels, watermark, logo from TradingView, decorative objects, or mockup scene. Only one icon, no variants or grid.
